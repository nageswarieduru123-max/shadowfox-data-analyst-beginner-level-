# ShadowFox Data Analyst Internship – Beginner Level

## 📊 Sales Performance Analysis & Dashboard

This project was completed as part of the ShadowFox Data Analyst Internship – Beginner Level.

## 🎯 Objective

The objective of this project is to analyze sales data and identify important business trends, performance patterns, and insights using spreadsheet-based analysis.

## 🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Data Analysis
- Charts & Dashboard

## 📁 Dataset

The dataset contains sales transactions with the following fields:

- Order Date
- Product
- Category
- Region
- Quantity
- Sales
- Profit

## 📈 Analysis Performed

The project includes:

- Total Sales analysis
- Total Profit analysis
- Total Quantity and Orders
- Average Order Value
- Profit Margin
- Monthly Sales Trend
- Category-wise Sales
- Region-wise Sales
- Product-wise Sales
- Business Insights

## 📊 Dashboard

An interactive-style Excel dashboard was created to present key metrics and visualizations clearly.

## 💡 Key Insights

The analysis helps identify:

- Top-performing products
- Best-performing categories
- Highest-sales regions
- Monthly sales trends
- Overall sales and profitability

## 📂 Project Files

- `shadowfox_sales_dataset.csv` – Raw sales dataset
- `ShadowFox_Data_Analysis.xlsx` – Complete analysis and dashboard
